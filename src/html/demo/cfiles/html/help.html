CFiles — Help

CFiles is a browser-based viewer and editor for JSON, YAML, CSV, TXT and BIN files. Everything runs locally in your browser: files are never uploaded anywhere.

Opening files

There is a single Open… action. You can also drag & drop files anywhere on the page or paste text with Ctrl+V. CFiles detects the type automatically and loads the matching viewer & editor:

TypeHow it is detectedViewer / editor
JSON.json extension or content that parses as JSONKey-value tree + raw source
YAML.yml/.yaml or mostly key: value / - item lines that parse as YAMLKey-value tree (list “-” markers shown as indented dashes) + raw source
CSV.csv/.tsv or lines with a consistent delimiter (, ; | tab)Editable table + raw source
TXTAny other textText editor with line numbers, find & replace
BIN.bin and other binary extensions, or content with NUL / control bytesTwo panes: HEX or OCTAL bytes + decoded text

If the guess is wrong, use View as above the editor to pick another type.

JSON & YAML

  • Edit keys and values in place. Use the type selector (appears on hover) to change a value’s type.
  • + adds a key/item, ⧉ duplicates, ✕ deletes.
  • Switch to Source to edit the raw text; syntax errors are reported with line/column.
  • Note: editing in the tree re-writes YAML, so YAML comments are not kept. Editing in Source keeps the text as you type it.

CSV

  • Click a cell to edit; Enter/arrows move between cells.
  • Click a row number or a column letter to select it, then use − Row / − Column. ⇅ sorts.
  • Change the delimiter or toggle the header row from the toolbar. Large tables are paged (200 rows per page).

BIN (binary)

  • Choose HEX or OCTAL for the byte pane; the choice is remembered.
  • The right pane shows the decoded characters (ASCII, UTF-8, Latin-1, Greek ISO-8859-7 / Windows-1253). Both panes scroll together.
  • Click a byte and type 2 hex digits (or 3 octal digits, max 377) to overwrite it, or type a character in the text pane. Ctrl+Z undoes.
  • Go to offset accepts 1024, 0x400, 0o2000. Find searches text or byte sequences (e.g. DE AD BE EF).
  • The Inspector shows the selected byte as integers / floats in little- and big-endian.

Create Synthetic Files

Generates test data as JSON, YAML, CSV or TXT. Binary files are intentionally excluded for security reasons.

  • Local generator (offline): random combinations from built-in tables (English or Greek names, cities, products, logs…). Pick a preset or individual fields; an optional seed makes results repeatable.
  • AI (LLM): describe the data in your own words. Calls go straight from your browser to the provider — no server is involved.
    • WebLLM — the model runs inside your browser via WebGPU (recent Chrome / Edge). Free, no key, and your prompt never leaves the device. The first run downloads the model (~1 GB), which the browser then caches.
    • OpenRouter, Groq, Google Gemini — free tiers using your own API key. The key is sent only to that provider and is stored in this browser only if you tick “Remember key”.
    • Custom — any OpenAI-compatible endpoint, e.g. a local Ollama server (OLLAMA_ORIGINS must allow the page’s origin).
    If the AI request fails, CFiles can fall back to the local generator automatically.

Saving & converting

Save (Ctrl+S) downloads the file — or, in Chromium-based browsers, opens a “Save as” dialog. Convert creates a new file, e.g. JSON → YAML, YAML → JSON, CSV ↔ JSON/YAML (array of objects).

Keyboard shortcuts

Ctrl+OOpen files
Ctrl+SSave
Ctrl+VPaste text as a new file (when no field is focused)
Ctrl+FFind (text editor)
