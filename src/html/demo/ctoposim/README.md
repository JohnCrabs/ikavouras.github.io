# CTopoSim — Προσομοιωτής Πολυγωνομετρίας & Ταχυμετρίας

Εκπαιδευτική πλατφόρμα σε απλή HTML/CSS/JavaScript, που τρέχει εξ ολοκλήρου στον browser (κατάλληλη για GitHub Pages).
Ο φοιτητής σχεδιάζει μια πολυγωνομετρική όδευση σε χάρτη ΕΓΣΑ 87, παίρνει προσομοιωμένες μετρήσεις υπαίθρου με τυχαία σφάλματα,
τις ανάγει, επιλύει την όδευση, κάνει ταχυμετρία και βαθμολογείται.

## Φάσεις

1. **Περιοχή & στάσεις**: ορισμός περιοχής μελέτης (έως 4 km²), φόρτωση DEM και κτιρίων OSM, τοποθέτηση στάσεων με κλικ.
   Τα δύο πρώτα κλικ γίνονται τα γνωστά T1, T2 και τα δύο τελευταία τα T3, T4. Με snap στο T2 και στο T1 η όδευση γίνεται κλειστή.
   Η οπτική επαφή κάθε σκόπευσης ελέγχεται με το DEM και τα κτίρια, και για κάθε πλευρά εμφανίζεται τομή εδάφους.
2. **Έντυπο πολυγωνομετρίας**: μετρήσεις σε δύο θέσεις τηλεσκοπίου (Hz, V, S, i, t), με σφάλμα σκόπευσης, σφάλμα δείκτη,
   καμπυλότητα/διάθλαση και τυχαία σφάλματα. Λήψη σε CSV (Excel) ή σε εκτυπώσιμη μορφή/PDF.
3. **Ανηγμένες μετρήσεις**: υποβολή CSV/TXT με β, D, Δh και σύγκριση με τις τιμές που προκύπτουν από το έντυπο.
4. **Επίλυση όδευσης**: υποβολή των σφαλμάτων κλεισίματος και των τελικών E, N, H, και βαθμολόγηση.
5. **Ταχυμετρία**: στάση οργάνου, μηδενισμός, σκόπευση σημείων (Hz, V, S σε 1η θέση) με έλεγχο ορατότητας, και υποβολή συντεταγμένων.

Κάθε καρτέλα έχει και υποκαρτέλα **Θεωρία**, με τύπους και καθοδήγηση χωρίς λύσεις.

## Δεδομένα

| Πηγή | Χρήση |
|---|---|
| AWS Terrain Tiles (Terrarium, z15) | Πρόχειρο DEM για όλη την Ελλάδα, σκίαση αναγλύφου |
| OpenStreetMap / Overpass API | Περιγράμματα και ύψη κτιρίων (`height`, `building:levels` × 3.2 m, αλλιώς 3 όροφοι) |
| Εθνικό Κτηματολόγιο, Esri, OSM | Υπόβαθρα χάρτη |
| proj4js | Μετασχηματισμός WGS84 ↔ ΕΓΣΑ 87 (EPSG:2100) |
| KaTeX | Μαθηματικοί τύποι στη θεωρία |

## Δημοσίευση σε GitHub Pages

1. Ανέβασε τα περιεχόμενα του φακέλου σε ένα αποθετήριο: `index.html`, `css/`, `js/`, `.nojekyll`.
2. Πήγαινε στο **Settings → Pages → Build and deployment → Source: Deploy from a branch**, και διάλεξε `main` και `/ (root)`.
3. Η εφαρμογή θα είναι διαθέσιμη στο `https://<χρήστης>.github.io/<αποθετήριο>/`.

Για τοπική δοκιμή τρέξε `python -m http.server` μέσα στον φάκελο και άνοιξε το `http://localhost:8000`.

## Σημειώσεις για τον διδάσκοντα

- Τα τυχαία σφάλματα παράγονται από το ονοματεπώνυμο, τον ΑΜ και τις θέσεις των στάσεων, οπότε κάθε φοιτητής έχει δικά του δεδομένα.
- Η εργασία αποθηκεύεται στον browser (localStorage) και εξάγεται ως αρχείο JSON (💾). Η αναφορά βαθμολογίας έχει κωδικό ελέγχου,
  που επαληθεύεται αν ανοίξεις το αρχείο έργου του φοιτητή.
- Επειδή όλα εκτελούνται στον browser, ένας έμπειρος χρήστης μπορεί να δει τις αναμενόμενες τιμές με τα developer tools.
  Η βαθμολογία είναι κατάλληλη για αυτοαξιολόγηση και άσκηση. Για εξέταση χρειάζεται έλεγχος του αρχείου έργου από τον διδάσκοντα.
